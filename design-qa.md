## Условия

Desktop CSS viewport 1363×936, browser capture той же плотности. Референс 1487×1058 масштабирован до ширины 1363; высота приведена к 936, без device frame. Полное совместное сравнение и отдельный crop просмотрены вместе.

Состояние: ноябрь 2026, тестовая сессия владельца, реальные запросы к изолированной тестовой SQLite, синтетический ученик с явной пометкой и тестовый платёж. Числа макета не скопированы. Пользовательская установка создаёт пустую базу.

В браузерной среде использована отдельная фикстура входа с созданием тестовой сессии на сервере, чтобы проверить UI без запроса пользовательского пароля. Этот маршрут есть только в одноразовой среде проверки, его нет в исходниках патча. Для iframe адаптивной проверки только в этой среде разрешён same-origin frame. В поставляемом сервере frame-ancestors 'none'. Настоящие вход/выход через форму и сессии проверены HTTP-интеграционными тестами.

## Пять поверхностей

- Typography: Inter для UI, умеренный Oswald в заголовках. Таблицы 14 px; поля имеют видимые подписи. Форма входа использует те же шрифты. Длинное имя в мобильной верхней панели обрезается с ellipsis, не вытесняя выход.
- Layout: тёмная боковая навигация, светлая область, красное основное действие, три показателя, широкая левая таблица/правая подборка. Нижние панели на desktop выровнены по высоте; на узком экране идут последовательно. На mobile закрытая навигация inert, в открытой фокус ограничен меню.
- Tokens: navy #121e36, red #bf1932, фон #f8f9fb, радиус 9 px, спокойные границы и тени, нет декоративных ↗.
- Assets: настоящий исходный logo-fed.png на белой подложке, Bootstrap Icons с лицензией локально. Знак из изображения не воспроизводился. Картинки новостей выбираются из существующих файлов, загрузка медиатеки пока не подключена.
- Copy: «Рабочая панель», действительный пользователь/роль/выход, «Сохранено» только после ответа API. Нет демосохранения записей во вкладке. «Без платежей» не заявляет долг. Запланированные разделы отключены.

## Итерации

1. Этап 08.1 дал проверенную адаптивную оболочку. На этапе 08.2 заменено локальное хранилище записей серверным API; предупреждение о демоданных убрано, добавлены реальные роль/выход и форма входа.
2. После появления реального имени выявлен риск вытеснения мобильных кнопок длинной строкой. Добавлено ограничение ширины имени, повторный mobile capture подтвердил доступность меню, ссылки на сайт и выхода.
3. Подсказка кнопки публикации исправлена на «следующий этап», поскольку сервер уже подключён, а право публикации ещё не согласовано.
4. Итоговое полное сравнение qa-server-comparison.jpg и сфокусированное qa-server-focus.jpg: компоновка сохранена, новых P0/P1/P2 не обнаружено. Отличия числа строк и показателей — данные тестовой базы. Правый список пуст, поскольку у единственного тестового ученика есть платёж.
