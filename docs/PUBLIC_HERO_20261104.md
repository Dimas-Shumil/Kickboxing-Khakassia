# Единый hero публичных разделов

Применять поверх этапа 08.3: скопировать содержимое архива в корень проекта с заменой. Зависимости и миграции не нужны. Запуск: npm run dev. Обновить страницы Ctrl+F5.

Обновлены /public/federation.html, /public/news.html, /public/competitions.html, /public/contacts.html. Общий повторяемый компонент _page-hero.scss подключён в четыре независимых SCSS. На всех страницах фото hall-archive.webp, одинаковая типографика, затемнение и минимальная высота 640px (620px на мобильном). При увеличении текста блок может расти, чтобы не обрезать содержимое. Тексты и кнопки сохранены.

SCSS скомпилирован в обычный и минифицированный CSS для каждой страницы. Пути к фото и подключение компонента проверены. Автоматическая визуальная проверка не выполнена: в среде нет установленного браузера Chromium. Проверьте четыре страницы на широком экране и телефоне, отсутствие обрезанного текста и горизонтальной прокрутки.

## Создание владельца после 08.3

Скрипт npm run user:create заменён командой node prisma/create-admin.js.
В .env заполнить ADMIN_LOGIN, ADMIN_PASSWORD (12–256 символов), ADMIN_NAME и ADMIN_ROLE=OWNER. Затем выполнить node prisma/create-admin.js и npm run dev. После создания удалить значение ADMIN_PASSWORD из .env. При существующей учётной записи создавать владельца заново не требуется. Повторный запуск для существующего логина сбрасывает пароль и отзывает сессии.
