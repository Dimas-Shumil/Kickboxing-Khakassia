# Единый радиус кнопок

Применять поверх текущих патчей: скопировать содержимое архива в корень с заменой файлов. Обновить страницу Ctrl+F5. Если сервер остановлен: npm run dev. Установка зависимостей и миграции не нужны.

Радиус кнопок публичного сайта и админки — 7px (как у прежних кнопок админки). Значение задаётся в site/sass/base/_variables.scss: $radius-button. Общий компонент components/_buttons.scss подключён через base и отдельно в независимый admin.scss. Стили страниц по-прежнему собираются независимо.

Удалены декоративная SVG-стрелка в главной hero-кнопке и стрелки рядом с текстом ссылок главной. Стрелки листания галереи и списков сохранены как элементы управления.

Все страничные SCSS перекомпилированы в CSS и min.css. Визуальная проверка браузером в этой среде недоступна. Вручную проверить главную, разделы сайта и админку: одинаковые углы кнопок, сохранённые подписи и работа листания галереи.
