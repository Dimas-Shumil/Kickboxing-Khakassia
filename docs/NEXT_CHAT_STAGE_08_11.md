# ПРОМТ ДЛЯ СЛЕДУЮЩЕГО ЧАТА — Федерация кикбоксинга Хакасии, этап 08.11

Продолжаем проект Федерации кикбоксинга Республики Хакасия. Я прикладываю СВЕЖИЙ ПОЛНЫЙ ZIP после 08.10 — только он является актуальным источником. Сначала распакуй и изучи весь код, документацию, тесты, миграции. Не накладывай старые патчи наугад.

Стек Node 24, Express ESM, Prisma 6.19.3, SQLite, HTML/SCSS/Vanilla JS, структура RioCar. Без React/EJS. Отдельные SCSS entrypoint страниц, общий дизайн, hero, favicon, border-radius 7px, чистые публичные URL, четыре разных шаблона людей и смена hover-фотографии легенды — сохранить.

Подэтапы до 08.8: новости, публичные люди, соревнования, история и архив, документы, медиатека, главная и контакты. Подэтап 08.9: один приватный зал — группы, тренировки, посещения, ученики, фактические оплаты и сводка; без задолженностей, просрочек, автоматических начислений и второго зала. Подэтап 08.10: аналитика контента и зала, журнал действий с фильтрацией, строгие права редактора и владельца. Документы: `docs/STAGE_08_9_GYM.md`, `docs/STAGE_08_10_ANALYTICS.md`. Для 08.10 не было миграций.

**Перед новым этапом** установить патч 08.10, выполнить на своём Node24 `npm ci`, `npx prisma generate`, `npx prisma migrate deploy`, `npm test`, `npm run dev`; подтвердить HTTP-интеграционные тесты 08.9 и 08.10 и мобильный интерфейс. Сообщить результат, исправить ошибки, если есть. Предыдущие 11/11 изолированных тестов не являются подтверждением полного тестирования.

**Предлагаемый 08.11** — техническая готовность: конфигурация и безопасный деплой, SEO и индексация только разрешённых публичных страниц, карта сайта, robots, обработка ошибок и пустых состояний, аудит безопасности и журналов, резервные копии с восстановлением (сначала согласовать периодичность/место хранения и политику доступа). Не разворачивать на VPS и не внедрять бэкапы/экспорт без явного решения владельца.

Правила: пользовательские БД и загрузки не менять, новые миграции только аддитивные, тестировать на отдельных временных БД. Сохранить роль `OWNER` для приватного зала, роль `EDITOR` только для редактирования контента. Не добавлять финансовую логику долгов или сроков платежей. Без git commit/push/deploy. Результат: ZIP-патч только изменений без `.env`, баз, медиа, `.git`, `node_modules`; Windows CMD; отчёт реальных проверок, ручной тест-план, документация и следующий промт.
